API REST con Spring Boot

OneVet API

Proyecto individual desarrollado para el Módulo 6, orientado a la gestión de productos mediante una API REST.

El sistema permite registrar, consultar, actualizar y eliminar productos, utilizando Spring Boot, Spring MVC, Spring Data JPA y respuestas en formato JSON.

La temática veterinaria se usa como contexto visual y académico, manteniendo el enfoque principal en la construcción de una API REST funcional.
